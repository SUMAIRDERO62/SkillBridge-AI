# Architecture and Project Decisions

## Decision 001 — Project Structure
**Status:** Accepted

Use separate frontend, backend, database, assets, and docs directories.

## Decision 002 — Frontend
**Choice:** Next.js with Tailwind CSS

**Reason:** Build a modern, responsive web application.

## Decision 003 — Backend
**Choice:** Next.js API Routes

**Reason:** Keep initial backend development simple.

## Decision 004 — Database and Authentication
**Choice:** Supabase

**Reason:** Provide database and authentication capabilities.

## Decision 005 — AI Provider
**Choice:** Gemini API

**Reason:** Integrate AI-powered roadmap generation.

## Decision 006 — Deployment
**Choice:** Vercel

**Reason:** Deploy the web application.

## Decision 007 — MVP Scope
**Status:** Planned

- Career selection
- Personalized roadmap generation
- Progress tracking
- Free learning resource recommendations
