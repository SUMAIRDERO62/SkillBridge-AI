# SkillBridge AI

## Mission

Help students find the shortest path from learning to earning.

## Problem

Students don't know:

- What to learn
- In what order
- Which projects to build
- Which skills industry requires

## Solution

AI-powered mentor that creates:

- Personalized roadmap
- Weekly learning plans
- Skill tracking
- Project recommendations
- Career guidance

## Target Users

- Students
- Beginners
- Career changers
- Self learners

## Long Term Goal

Become an AI career mentor platform.
